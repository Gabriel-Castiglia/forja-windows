- First release: Win32 window in C, static and portable; length 4–128, 1–50 passwords, avoid ambiguous

- Command line `/out`, `/len`, `/count`, `/ambiguous`, `/lang`, `/theme`, `/shot`.
- User guides in three languages (Word and PDF).
